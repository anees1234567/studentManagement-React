## Tech Stack

- **Frontend:** React 18, Vite, Material-UI (MUI), React Router, React Hook Form, React Query
- **Language:** TypeScript / JavaScript
- **State Management:** Context API / Redux Toolkit (optional)
- **HTTP Requests:** Axios
- **Styling:** Tailwind CSS, MUI components
- **Backend:** Node.js + Express.js (separate repository)




## Installation

 **Clone the repository**

- git clone https://github.com/anees1234567/studentManagement-React.git
- cd studentManagement-React
- git checkout branch-studentDetailsEdit

**Install dependencies**
- npm install
- npm run dev
